Checkpoint started from `e503ea0c`; official-valid incumbent remains unmodified

## Fresh architecture-aware census

An isolated census branch records the 123 forward and 123 reverse R125 A-tick
boundaries before postprocessing. The external `gpu_skywalk` CPU reference was
extended to snapshot the exact bit-sliced forward state at each boundary and to
evaluate the test-proven integer fold predicate at widths 55--58. All 123
forward boundaries have condition-stack depth zero. The 100K frozen-corpus run
took 167.108 seconds of CPU simulation and produced:

- 57-bit: 11 unique escapes, every one overlapping a value failure.
- 58-bit: repairs 7 of the 11; sites 35, 41, 63, and pair-site 82 remain.
- 56-bit: 18 unique escapes, seven new relative to 57, at pair-sites
  1, 5, 37, 50, 56, 85, and 109.
- The 56- and 57-bit masks are identical at pair-sites
  2, 11, 15, 16, 35, 41, 51, 63, 71, 80, and 82.
- Pair-site 80 represents four raw ticks, 80--83. Fresh raw tick and normalized
  pair-site identities are retained separately; no E040/E046 site table was used.

Artifacts are in `scratch/official87-validation/r125-census-{10k,100k}.csv`.
The census explains only fold-core escapes; comparison-boundary and reverse-path
failures require focused circuit experiments.

## RTX 4090 full-circuit throughput and nonce feasibility

Hardware: RTX 4090 24,564 MiB, driver 595.91.07, CUDA 12.8. The architecture-
matched full-circuit replay is validated against CPU on identical 10K inputs.
For E050, 100K full shots take 17.696 seconds kernel and 18.482 seconds cold
(about 5,410 shots/s). The current disk pack plus cold replay takes 33.343 +
18.482 = 51.825 seconds (about 1,930 shots/s). Fresh nonce-like SHAKE plus CPU
secp256k1 reference preparation takes 3.904 seconds/100K on 64 CPU threads, so
the full circuit, not input construction, is the dominant integrated cost.

Independent 100K union rates are official87 216/100K=0.2160%, E048
213/100K=0.2130%, E050 212/100K=0.2120%; all ancilla counts are zero. Under
the explicit and unverified IID assumption that this union rate transfers to
each of 9,024 independent hash-derived shots, E050 has clean probability
`(1-0.00212)^9024 = 4.81665e-9`, about one in 207.6 million nonces. Its 95%
Wilson endpoints imply a very broad one-in-18.6M to one-in-3.27B range.

At the current measured pack+replay rate (about 770 complete nonces/hour), the
point-estimate expected time is 30.8 years; success probabilities are 0.000371%,
0.002225%, and 0.008898% within 1, 6, and 24 hours. An in-memory integrated
estimate using measured input-prep plus cold CUDA time is about 1,789 nonces/hour:
13.2 years expected, with 0.000861%, 0.005169%, and 0.020673% success in 1, 6,
and 24 hours. These are feasibility estimates, not a search result.

The legacy toolkit's Dialog/TrailMix GCD filter rates are not R125 rates and
were not used as a correctness oracle. The external implementation is based on
toolkit commit `2fdcec6e755b34cdf7c11b9e36e9abf03701e6ec`: byte-exact Keccak/SHAKE
state handling, CUDA launch/error/timing structure, batch serialization, and
the block scheduling pattern were reused. The R125 evaluator itself is a new
architecture-matched operation-stream replay; it does not use the old GCD
predicate. External sources live under `ecdsa-research/gpu_skywalk`, outside
the challenge tree.

## Bounded local nonce pilot and progressive R125 filter

The authorized local-only E048 pilot evaluated nonces 0--291 (292 unique
nonces), all with the complete 9,024-shot R125 operation stream. No clean nonce
was found. Nonces 36--291 form the fixed 256-nonce classifier corpus: union
failures range from 11 to 31, mean 19.5117, with zero ancilla failures. Full
pack preparation took 203.723 seconds and cold CUDA replay 339.603 seconds,
543.326 seconds end to end (0.4712 nonce/s). Kernel-only throughput is 0.7611
nonce/s. The complete replay peaked at 1,790 MiB in the earlier pilot sample.
The attempted 512-nonce extension produced an incomplete pack after a network
filesystem stall and is not counted or used.

The filter completes the circuit for a prefix of independent shots and hard
rejects only after observing a final value, phase, or ancilla violation in a
completed shot. A failure in one shot cannot be cancelled by another shot, so
this rejection rule is conservative. A prefix pass is explicitly `uncertain`,
never accepted as clean. Phase failures are used only after the complete
circuit for that shot; partial in-circuit phase state is never a rejection
predicate.

Direct filters on the 256 fully labeled E048 nonces give:

| Shots | hard rejects | uncertain/dirty pass-through | prefix-mask disagreements | pack + cold GPU | nonce/s |
|---:|---:|---:|---:|---:|---:|
| 64 | 28 | 228 | 0 | 13.040 s | 19.632 |
| 512 | 175 | 81 | 0 | 39.779 s | 6.436 |
| 1,024 | 234 | 22 | 0 | 67.099 s | 3.815 |
| 2,048 | 253 | 3 | 0 | 129.855 s | 1.971 |

The 1,024-shot time above uses a screening-specialized CUDA kernel that omits
Toffoli accounting. It preserves every value/phase/ancilla mask (zero mask
disagreements over 4,096 batches), and cuts the kernel from 39.219 to 33.314
seconds. It is valid only for screening, not resource measurement.

A deployable progressive schedule regenerates only surviving nonces, using an
explicit noncontiguous nonce-list mode added to the external Rust packer. Its
generated 22-survivor E048 pack is byte-identical to the corresponding rows
selected from the exhaustive pack (SHA-256
`d5f5a21fab9f5d80fade29fb0b9809379d7dfcb8988c92cb5060106a9034bced`).
Measured stages are:

| Stage | input -> pass | pack | cold GPU | cumulative property |
|---:|---:|---:|---:|---|
| 512 | 256 -> 81 | 17.563 s | 19.129 s | 175 conservative rejects |
| 1,024 | 81 -> 22 | 14.073 s | 12.820 s | 234 cumulative rejects |
| 2,048 | 22 -> 3 | 11.086 s | 6.709 s | 253 cumulative rejects |
| 9,024 | 3 -> 0 | 10.756 s | 6.583 s | all 256 confirmed dirty |

Total end-to-end time is 98.719 seconds, 2.593 nonce/s and a measured 5.504x
speedup over exhaustive full replay. Every stage has zero prefix-mask
disagreements against the exhaustive masks. The 512-shot stage reaches 100%
GPU utilization, peaks at 658 MiB and 175.44 W in 120 samples. The known-clean
official87 nonce `1293570722` passes 512, 1,024, 2,048, and 9,024-shot controls;
the complete CPU/GPU control remains 0 value / 0 phase / 0 ancilla. This is one
clean control, not statistical proof of zero false negatives. E048 has no known
clean nonce in this corpus, so its clean-candidate recall is not empirically
estimable from these 256 all-dirty labels.

The phase-projected/value-and-ancilla-only 1,024-shot kernel deletes 638,332
pure phase operations and has zero value/ancilla mask disagreements. With
screen-only specialization it takes 33.676 seconds cold versus 34.308 for all
failure categories, but rejects only 229 rather than 234 nonces. The 0.632
second saving is dominated by five extra expensive survivors, so this mode is
not selected. A serial one-block-per-nonce early-exit kernel is also rejected:
it is only 2.94x faster in the dirty kernel test and becomes extremely slow on
clean candidates because it destroys shot parallelism. Carry-escape census
masks remain heuristic risk scores only; they are not hard rejection rules.

## Approximate GPU screening checkpoint (2026-11-06 07:30Z)

The external `jieyilong/ecdsafail_gpu_toolkit` clone now has an R125 research
state dumper, a runtime GCD-depth knob, a configurable shot-prefix knob, and an
architecture-aware CUDA filter. No challenge source, Cargo configuration,
evaluator, scoring code, or protected manifest was changed for this work.

The first generic binary-GCD approximation was rejected as an R125 risk model.
At limit 261 it passes the known-clean official87 nonce and runs at 718--734
nonce/s over a complete packet, but on the 256 fully labelled E048 packets its
high-risk group has 19.24 exact union failures/packet versus 19.88 in its pass
group. More aggressive prefix modes reach toolkit-class raw rates (41.7k
nonce/s at limit 258 over 64 shots), but the clean control fails when that mode
is extended to 256 shots. The GCD result is retained only as an explicitly
heuristic ranking tier.

The new `GPU_FILTER=r125_fold` path reuses the toolkit's R125 SHAKE tail,
secp256k1 comb multiplication, block-per-nonce scheduling, batch inversion and
large-comb tables. It classically replays the 124-step pair-aware A2 divide
walk, the modular payload update, and the actual 57-bit forward fold carry
predicate. Its tick-0 choice uses the public A2 reference rule rather than the
circuit's specialized re-derived tick-0 letter, so it is an approximate risk
filter and must not be used as a full-circuit verdict.

Measured on RTX 4090 with comb22/wave128 over 8,192 E048 nonces:

| Filter | raw rate | pass fraction | evidence |
|---|---:|---:|---|
| exact progressive replay | 2.593 nonce/s | exact | zero prefix-mask disagreements |
| R125 fold approximation | 1,898 nonce/s | 56.25% | 107/256 dirty packets caught; known clean passes |
| generic GCD limit 261 | 726 nonce/s | 45.70% | known clean passes; no positive failure-count enrichment |
| fold then GCD | 526 nonce/s | 22.51% | heuristic intersection; every survivor still needs exact replay |

The R125 filter's rejected labelled group has 20.11 exact union failures per
packet versus 19.08 in its pass group. On the available controls this gives
107 true dirty detections, 149 dirty pass-throughs, one observed clean
pass-through and zero observed clean rejections. One clean case is not enough
to estimate clean-candidate recall or claim zero false negatives. All rejected
nonces therefore remain in a deferred high-risk queue; they are ranked, not
silently discarded.

The exact 512/1,024/2,048 stages after the combined fold+GCD pilot processed
the fully labelled 256-nonce E048 range in 52.785 seconds: 64 approximate
survivors -> 19 -> 7 -> 0. The two approximate filter processes add 2.119
seconds wall time at this small batch size, for 54.904 seconds end to end,
4.663 original nonce/s including CPU pack generation and process startup, or
1.80x the prior 2.593 nonce/s exact-progressive workflow. At large-batch steady state, using measured
filter rates and a 22.51% survivor fraction projects to 11.273 original
nonce/s (4.35x), close to the legacy toolkit's roughly 10k nonce/s class, but
that projection is a throughput result, not a clean-recall result.

The fold-filter utilization run measured 1,877 nonce/s, 88.4% mean / 100% peak
GPU utilization, 3,474 MiB peak VRAM and 288.4 W peak board power. The known
official-valid nonce `1293570722` passes the full 9,024-shot fold filter and the
complete exact evaluator. The 256 E048 labels are all dirty, so a statistically
useful clean recall estimate remains unavailable.
